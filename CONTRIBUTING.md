# Contributing to Lahore Software Houses Directory 🚀

First off, thank you for considering contributing to this list! It's people like you who make this resource valuable for the entire tech community in Lahore.

There are many ways to contribute, from adding new companies to fixing broken links.

## 📝 How Can I Contribute?

### 1. Adding a New Company
If you know a software house that isn't on the list:
* Ensure the company is physically located or has a major office in **Lahore**.
* Check if the company is already listed to avoid duplicates.
* Add the company to the appropriate table in **alphabetical order**.
* Please provide as much information as possible (Website, LinkedIn, etc.).

### 2. Updating Existing Information
If you find a broken link, a company that has rebranded, or one that has closed down, please submit a PR to update the record.

### 3. Improving the Repository
If you have ideas on how to make this list better (e.g., better categorization, adding maps, etc.), feel free to open an issue or submit a PR with your suggestions.

## 🛠 The Process

1.  **Fork** the repository.
2.  **Create a branch** for your changes (`git checkout -b add-new-company`).
3.  **Commit** your changes with a clear message (`git commit -m "Add [Company Name] to the list"`).
4.  **Push** to your fork (`git push origin add-new-company`).
5.  **Open a Pull Request** and describe what you've added or changed.

## ✅ Contribution Guidelines
* **Quality over Quantity:** Please only add legitimate software houses or IT-related firms.
* **Format:** Stick to the Markdown table format used in the `README.md`.
* **Links:** Ensure all URLs start with `https://`.

## 🌟 Recognition
All contributors will have their GitHub profiles showcased in the contributors' section of the README. Every bit of help counts!
